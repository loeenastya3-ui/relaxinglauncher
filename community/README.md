# Данные сообщества Relaxing Launcher

Эти файлы обслуживают каталог участников на странице «Люди» и публичные
профили, пока живой сервер ещё не запущен. Лаунчер читает их через jsDelivr:

```
https://cdn.jsdelivr.net/gh/loeenastya3-ui/relaxinglauncher@main/community/<путь>
```

## Как добавить участника

1. Добавьте запись в `community/index.json` (массив `users`):

   ```json
   { "id": "мой-id", "nickname": "Ник", "platform": "elyby", "bio": "Короткое описание" }
   ```

2. Создайте файл `community/people/мой-id.json` (можно взять за шаблон
   демо-профили) — он открывает профиль по кнопке в каталоге.

3. По желанию положите миниатюру лица (например, 64×64 PNG) в
   `community/skins/head/мой-id.png` — вместо инициалов появится картинка.

Пожалуйста, не редактируйте чужие записи без их согласия.
